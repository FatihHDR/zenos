05 / PERTIMBANGAN TEKNOLOGI

Alasan pemilihan
komponen.

Komponen dipilih berdasarkan kebutuhan data dan lingkungan eksperimen. Trade-off kinerja dan integrasi dicatat bersama tiap keputusan.

Qdrant

VS BASIS DATA TERPISAH
Satu koleksi · dense + sparse

Named vectors dan RRF didukung dalam satu basis data, sehingga indeks dense dan sparse tidak perlu dikelola sebagai layanan terpisah.

BGE-M3

VS DUA MODEL EMBEDDING
Dense + sparse · satu model

Mendukung korpus multibahasa Indonesia–Inggris dan menghasilkan dua representasi dalam satu proses inferensi.

Reranker lokal

VS COHERE API
bge-reranker-v2-m3 · tanpa API key

Memungkinkan eksperimen lokal. Namun, waktu reranking pada CPU jauh melampaui target; Cohere tersedia sebagai provider alternatif, tetapi belum diuji.

QdrantManager

VS ABSTRAKSI LLAMAINDEX
Metadata chunk eksplisit

Pipeline memanggil QdrantManager untuk mengendalikan retrieval dan metadata sitasi. Wrapper LlamaIndex tetap tersedia untuk retriever.

Endpoint kompatibel OpenAI

VS KONEKSI ANTHROPIC LANGSUNG
Model aktif: Haiku melalui 9router

Endpoint yang tersedia digunakan dalam implementasi. PRD menargetkan Claude Sonnet; kualitas relatif kedua model belum dievaluasi.

FastAPI + SSE

VS API TANPA KONTRAK TERBUKA
REST · streaming · OpenAPI 3.1

Kontrak dapat digunakan di Apidog/Postman. SSE mengirim potongan jawaban dan metadata penutup, termasuk TTFT.

Batas operasional: reranker lokal tercatat lambat pada CPU dan hasil latensinya terdampak tekanan memori. API Qdrant dan router belum memiliki autentikasi, sehingga deployment perlu dibatasi pada jaringan tepercaya.

09 / DAFTAR PUSTAKA

Literatur dan
sumber proyek.

Paper mendasari istilah dan metode yang dibahas. Dokumen proyek menjadi sumber utama untuk detail implementasi serta hasil.

RAG · LANDASAN KONSEP

Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

Lewis et al. · NeurIPS 2020 · arXiv:2005.11401
Rujukan konsep generasi yang menggabungkan model bahasa dengan pengetahuan eksternal hasil retrieval.

DENSE RETRIEVAL

Dense Passage Retrieval for Open-Domain Question Answering

Karpukhin et al. · EMNLP 2020, hlm. 6769–6781
Dasar pembahasan retrieval dense berbasis representasi vektor untuk pemilihan konteks.

FUSION · RRF

Reciprocal Rank Fusion Outperforms Condorcet and Individual Rank Learning Methods

Cormack, Clarke, dan Buettcher · SIGIR 2009, hlm. 758–759
Rujukan metode penggabungan peringkat yang digunakan pada pencarian hybrid Zenos.

EMBEDDING · BGE-M3

M3-Embedding: Multi-Linguality, Multi-Functionality, Multi-Granularity Text Embeddings Through Self-Knowledge Distillation

Chen et al. · 2024 · arXiv:2402.03216
Publikasi model yang mendukung pencarian multilingual serta representasi dense dan sparse BGE-M3.

RERANKING

Passage Re-ranking with BERT

Nogueira dan Cho · 2019 · arXiv:1901.04085
Rujukan penggunaan model cross-encoder untuk mengurutkan ulang kandidat passage berdasarkan query.

EVALUASI RAG · RAGAS

Ragas: Automated Evaluation of Retrieval Augmented Generation

Es et al. · 2023 · arXiv:2309.15217
Kerangka metrik untuk retrieval dan generasi RAG; tersedia secara opsional di proyek, belum dijalankan.
